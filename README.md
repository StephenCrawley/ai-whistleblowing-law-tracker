# AI Whistleblowing Law Tracker

NB: this is a personal project and is not affiliated with any organization. If you are considering raising a concern, seek legal advice or reach out to a whistleblower support org.

## Status

Work in progress.

- Done: 
    - Six law entries checked against official sources
    - JSON Schema and validator
    - Astro site with filters and a strict-CSP-ready build
    - Ansible base role (security updates, time sync, admin user)
    - SSH hardening
    - Firewall
    - Caddy with security headers
    - HTTPS deployment
- Next: CI/CD, a local open-weight LLM drafting pipeline with provenance, a threat model.

## Website

aiwhistleblowing.org

## What

A small, privacy-respecting static site summarising laws that protect people who raise concerns about AI, each entry checked against official sources.

## Why

To learn what laws and legislation exist providing whistleblower protections. Such protections seem ever-important today, when a growing number of frontier lab employees voice concern about AI-associated risks.
